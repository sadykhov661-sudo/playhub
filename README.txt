PLAYHUB — инструкция по публикации

1. Загрузи содержимое этой папки на GitHub Pages или Vercel.
2. После получения настоящего адреса сайта замени example.com в robots.txt и sitemap.xml на свой домен.
3. Добавь сайт в Google Search Console и Яндекс Вебмастер.
4. Отправь sitemap.xml на индексацию.

Важно: поисковая индексация не происходит мгновенно и появление сайта на первой странице не гарантируется.
